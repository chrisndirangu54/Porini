# Conservation drone integration boundary

Compatible open-source ecosystem to evaluate: PX4, MAVSDK, MAVLink, QGroundControl, ROS 2, MAVROS, OpenCV, GStreamer and suitable thermal camera SDKs.

Implemented now: observation mission request, administrator decision, auditable approval state. Approval is **not** takeoff. A certified pilot must independently validate airspace, local aviation permissions, weather, line-of-sight rules, battery reserve, safe standoff from wildlife and emergency procedures.

Future: companion computer read-only telemetry, geofenced observation plans, camera video ingress, abort authority, charging dock health, redundant collision checks. No autonomous pursuit, interception, weaponized payloads or dispatch to confront people.
